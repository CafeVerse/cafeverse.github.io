Installation Guide

🪟 Windows Installation

Option 1: Installer (Recommended)

  1. Download the .exe or .msi file
  2. Run the installer and follow setup steps
  3. Launch CaféVerse from Start Menu

Option 2: Portable Zip

  1. Download the .zip package
  2. Extract contents to your chosen folder
  3. Launch CafeVerse.exe directly

🐧 Linux Installation

Using AppImage

chmod +x CafeVerse-*.AppImage
./CafeVerse-*.AppImage

Using Debian Package 

sudo dpkg -i cafeverse-*.deb
